BIND HELPER — получить готовый EXE без установки Python на своём ПК

Важно: сам EXE должен быть собран на Windows. В этом комплекте настроена
автоматическая сборка на GitHub Actions. Python устанавливается только на
сервер сборки GitHub; на вашем компьютере Python не нужен.

ОДИН РАЗ ВЫПОЛНИТЕ:
1. Создайте бесплатный аккаунт на https://github.com/ (если его ещё нет).
2. Создайте новый репозиторий (можно Public или Private).
3. Загрузите в репозиторий ВСЕ файлы и папки из этого архива, включая скрытую
   папку .github. Удобнее всего: на странице репозитория нажать Add file →
   Upload files, затем перетащить содержимое распакованной папки.
4. Откройте вкладку Actions. Если GitHub попросит разрешить Actions — разрешите.
5. Выберите workflow "Build Windows EXE" и нажмите Run workflow.
6. Дождитесь зелёной галочки. Откройте завершённый запуск и скачайте артефакт
   BindHelper-Windows внизу страницы.
7. Распакуйте скачанный артефакт — внутри будет BindHelper.exe.

ДАЛЬШЕ:
Запускайте BindHelper.exe двойным щелчком. Python и библиотеки отдельно
устанавливать не требуется.

Программа предназначена для Windows 10/11. При первом запуске Windows SmartScreen
может показать предупреждение, потому что EXE не подписан цифровым сертификатом.
Запускайте только если доверяете исходному коду и сборке.

Горячие клавиши по умолчанию:
F1 — вставить номер, Enter, перейти к следующему.
F2 — вставить текст спича и Enter.
F3 — вставить выбранный файл и Enter.
F4 / F5 — следующий / предыдущий номер.

Перед отправкой поставьте курсор в поле целевого приложения. Сначала проверьте
работу на тестовом чате/поле. Приложение не отправляет сообщения само по сети:
оно имитирует Ctrl+V и Enter в активном окне.
